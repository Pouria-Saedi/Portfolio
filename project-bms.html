📋 Project Overview

The Building Management System (BMS) is a comprehensive smart home automation solution designed to revolutionize lighting control in residential and commercial spaces. This sophisticated system integrates advanced relay control technology with modern wireless communication protocols to provide seamless, intelligent lighting management.

Built around the powerful ESP32 microcontroller platform, the system supports multiple switch configurations (1-gang, 2-gang, 3-gang, and 4-gang) allowing flexible deployment across different room layouts and requirements. Users can control their lighting from anywhere in the world through cloud connectivity, or utilize local Bluetooth mesh networking for ultra-fast, reliable control without internet dependency.

The project encompasses complete hardware and firmware development, including custom PCB design, power management circuits, relay driver optimization, and a robust embedded software stack that ensures reliable operation 24/7.

💻 Technical Implementation

Hardware Architecture

The hardware design centers around the ESP32-WROOM-32 module, providing dual-core processing power at 240MHz with integrated Wi-Fi and Bluetooth capabilities. A custom 4-layer PCB design optimizes signal integrity, power distribution, and thermal management.

The power supply section features an AC-DC converter module providing regulated 5V/1A output, followed by a high-efficiency buck converter (MP2359) stepping down to 3.3V for the ESP32 and peripheral circuits. Each relay channel includes optocoupled isolation, flyback diode protection, and MOSFET-based drivers for silent, reliable switching.

Firmware Development

The embedded firmware is developed using ESP-IDF framework with FreeRTOS for real-time task management. The software architecture implements a modular design with separate tasks for:

  • Bluetooth Mesh Networking: Handles mesh provisioning, node-to-node communication, and message relay
  • Wi-Fi Management: Maintains cloud connectivity with automatic reconnection and fallback mechanisms
  • Relay Control: Manages switching logic, debouncing, and state persistence in NVS flash
  • MQTT Client: Handles publish/subscribe operations for remote control and status updates
  • OTA Manager: Validates and installs firmware updates securely

Cloud Integration

The system connects to AWS IoT Core using secure MQTT over TLS 1.2, with device authentication via X.509 certificates. A custom Node.js backend handles user management, device provisioning, and real-time command routing. Mobile apps (iOS/Android) communicate with the backend via RESTful APIs and receive instant updates through WebSocket connections.
