Complete System Overview

Five hardware modules form a self-healing BT Mesh network. Each node maintains local state and operates offline; when connectivity is restored the mesh reconciles state automatically. The MQTT bridge enables full remote control and sensor monitoring from the Flutter app over Wi-Fi.

Smart Touch Switch

Flush-mount 3-gang / 4-gang wall switch built as a two-PCB stack: a top controller/touch board and a bottom mains relay board, mated via four dual-pin inter-board headers. An OR-gate logic layer (SN74LVC1G32) allows either a physical capacitive touch or an incoming BT Mesh command to fire a relay independently — so the switch remains functional whether the MCU processes a packet or not.

  • MCU: ESP32-S3-WROOM-1-N16 (Wi-Fi + BT Mesh, 16 MB flash) with USB-D+/D− for native USB
  • Touch sensing: 4× TTP223-TD capacitive touch ICs (one per gang) with supplementary ring pads for extended touch area
  • Logic: 4× SN74LVC1G32DBVR OR gates combining touch and wireless relay signals; 10 kΩ pull-downs ensure defined logic low
  • Relay drivers: 4× SS8050 NPN transistors with 1 kΩ base resistors and flyback diodes; 4× HRS3FNH SPDT relays on mains board
  • LEDs: 6× WS2812B-2020 addressable RGB LEDs for per-gang status indication
  • Mains supply: HLK-3M05B isolated AC-DC (230 V → 5 V / 600 mA)
  • Logic supply: XL1509-3.3 synchronous step-down (5 V → 3.3 V)
  • Programming: Micro-USB connector; dedicated BOOT button with strapping resistors per ESP32-S3 spec

Smart Plug

Wi-Fi + Bluetooth Mesh smart plug with real-time power monitoring and a 3-digit 7-segment display. A two-PCB stacked assembly: a mains power/relay board and an ESP32 display/controller board connected via a 5-pin inter-board header (5 V, GND, REL, SAM, AMP). The ACS712 Hall-effect sensor provides ±30 A current measurement; a 1 MΩ / 10 kΩ resistor divider gives zero-crossing and RMS voltage estimation.

  • MCU: ESP32-WROOM-32-N4 (Wi-Fi + Bluetooth)
  • Mains supply: HLK-PM01 isolated AC-DC (230 V → 5 V)
  • Load switching: 5 V relay driven by SS8050 NPN with 1N4448W flyback diode
  • Current sensing: ACS712ELCTR-30A Hall-effect sensor; RC low-pass filter (1 kΩ + 100 nF) + envelope circuit
  • Voltage sampling: 1 MΩ / 10 kΩ divider with 10 µF smoothing cap for zero-crossing / RMS estimation
  • Display: FJ5361AH 3-digit 7-segment common-cathode driven directly from ESP32 GPIOs
  • Logic supply: AMS1117-3.3 LDO (5 V → 3.3 V) with 4× 22 µF bulk caps
  • User input: Toggle switch + momentary push-button with 10 kΩ pull-up; LDR light sensor

AI Voice Module

Fully offline voice control node — no cloud calls, no remote inference latency. The ESP32-S3's dual-core Xtensa LX7 paired with 8 MB OPI PSRAM provides enough headroom to run the I²S microphone capture pipeline, the custom wake-word detection model inference loop, and BT Mesh stack messaging simultaneously. Audio feedback is handled by a MAX98357 Class D I²S amplifier driving an onboard speaker.

  • MCU: ESP32-S3-WROOM-1-N16R8 — 16 MB flash + 8 MB OPI PSRAM for on-device AI inference
  • Microphone: I²S MEMS microphone (SD, WS, SCK, L/R lines to ESP32-S3 I²S peripheral)
  • Speaker output: MAX98357 Class D I²S amplifier (DIN, BCLK, LRC) → OUT+ / OUT− speaker pads
  • Power supply: MP1584 synchronous buck (5 V → 3.3 V) with 470 µF bulk cap for stability
  • USB: USB bridge IC for firmware flashing; slide switch for power cycling
  • LEDs: 4× WS2812B addressable RGB LEDs in daisy-chain for visual wake-word feedback
  • Form factor: Octagonal two-layer PCB with chamfered corners and four mounting holes
